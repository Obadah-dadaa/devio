# Devio — Software Company Website

Static website for **Devio** (websites, mobile apps, business software, design and branding), in
English and Arabic. Plain HTML, CSS and JavaScript, no build step.

## Structure

```
index.html            → page content in English (hero, services, process, work, why, contact)
css/style.css         → all styles; colour and spacing tokens are at the top (one accent: --accent)
js/main.js            → interactions + the ARABIC text (the `ar` dictionary at the top)
assets/icons/         → site icon set (generated by brand/build-brand.mjs)
assets/work/tahselly/ → screenshots, posters and launch film for the featured project
brand/                → the visual identity: logos, PNG exports, social, stationery, tokens, guidelines PDF
site.webmanifest      → icon manifest
CLAUDE.md, .claude/   → rules, permissions and design skills for Claude Code
```

## Brand

One accent, royal blue `#2A5CD6`, on deep navy `#070B18`; the site is dark only. The logo is the
"devio" wordmark with a square royal dot on the i. Sora for Latin headings, Readex Pro
for body text and all Arabic, JetBrains Mono for small labels. The full rules are in
`brand/Devio-Brand-Guidelines.pdf`; the values are in `brand/tokens.css` and `brand/tokens.json`.

To regenerate every logo, icon, social image and the PDF:

```
PUPPETEER_PATH=<path to puppeteer-core> node brand/build-brand.mjs --render
```

## Languages

Every text element in `index.html` carries a `data-i18n` key with the English text inside it. The
Arabic for the same key is in the `ar` object in `js/main.js`. Change a line in both places. The page
opens in the visitor's browser language, remembers their choice, and `?lang=ar` or `?lang=en` forces
one. Layout uses CSS logical properties, so Arabic mirrors without a second stylesheet.

## Change the work section

The featured project (Tahselly) is written directly in `index.html` under `#work`: five screenshots in
`.case-screen`, with one `.demo-step` button per screenshot sharing the same `data-key`. The other
projects are the `.more-row` items below it. Captions under the viewer are in `ui` in `js/main.js`.

## Motion and interaction

Every effect says something: the logo draws itself once on load (and again in the footer),
the hero headline rises word by word, the hero drawing builds a product in four stages (plan, design,
build, launch), signals travel along the page grid behind everything (a canvas, `#fx`), a ticker lists
what we make, each service has a small drawing that redraws when picked, the footer shows live UAE
time, the statement under the hero lights up word by word as you read
down the page, the Tahselly frame tilts upright as it scrolls into view and then plays through the real
product screens (click a step, or let it play), the services list shows what you get for
each one, sections settle in as you reach them, the process lines draw in order, one indicator marks the
current section, a thin bar shows how far down the page you are, the header steps aside while you read
and returns when you scroll up, and the form shakes the fields that need fixing. All motion uses
`transform`/`opacity` and switches off under `prefers-reduced-motion`. Without JavaScript all content is
still visible (in English).

## Contact form

There is no backend yet. After validation the form opens the visitor's email app with the message
filled in, addressed to `hello@devio.com`. Replace `sendMessage()` in `js/main.js` with a POST to the
Laravel API when it exists.

## Run locally

Open `index.html` in a browser, or serve the folder (`python -m http.server`).
